# 🚀 Installation & Setup

## Quick Start

```bash
# Clone the repository
git clone https://github.com/uricorn/base44-docs-tool.git
cd base44-docs-tool

# One-command setup
python3 setup.py

# Start using immediately
./b44 search "Google login"
./b44 get "/Getting-Started/FAQ"
```

## Installation Options

### Option 1: Direct Use (Recommended)
Clone and use directly in this repository:
```bash
git clone https://github.com/uricorn/base44-docs-tool.git
cd base44-docs-tool
python3 setup.py
./b44 search "authentication"
```

### Option 2: Install in Existing Project
Add the tool to your existing project:
```bash
# In your project directory
curl -O https://raw.githubusercontent.com/uricorn/base44-docs-tool/main/install-base44-tool.sh
chmod +x install-base44-tool.sh
./install-base44-tool.sh

# Tool will be installed in ./base44-tool/
cd base44-tool
./b44 search "your query"
```
